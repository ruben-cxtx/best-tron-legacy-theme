# Change Log

All notable changes to the Encom Tron Legacy Theme Pack will be documented in this file.

The format is based on [Keep a Changelog](http://keepachangelog.com/).

## [1.1.0] - 2026-05-03

### Added
- Added **Tron - Retro Grid**, a fourth retro Tron flavor with neon blue, green signal, and warm arcade accents.
- Added semantic highlighting support across all themes.
- Added broad syntax coverage for React, Next.js, Node, NestJS, Astro, Tailwind, HTML, CSS, SQL, Markdown, YAML, Docker, Kubernetes, GitLab CI, shell, and Python.
- Added richer workbench colors for tabs, panels, lists, settings, notifications, debug controls, Git decorations, minimap markers, breadcrumbs, peek views, and terminal ANSI colors.
- Added a generator-backed theme workflow with `npm run build` and `npm run check`.

### Changed
- Rebuilt Encom as the flagship flavor with a deeper blue-black Grid, brighter cyan circuitry, and more readable secondary accents.
- Improved Ares and CLU with fuller UI coverage, stronger terminal palettes, and clearer syntax separation.
- Moved sponsor metadata to the top-level VS Code manifest field.

## [0.0.2] - 2026-02-08

## [0.0.1] - 2026-02-08

### Added
- Initial release of Encom Tron Legacy Theme Pack
- Three distinct Tron-inspired themes:
  - **Tron Legacy - Encom**: Classic Encom corporate interface with sleek blues
  - **Tron - Ares**: Balanced blue and orange accents inspired by the character Ares
  - **Tron Legacy - CLU**: Aggressive orange highlights representing CLU's world
- Neon blue and orange color palettes inspired by the Tron Legacy movie
- Optimized syntax highlighting for multiple programming languages
- Enhanced readability with carefully selected contrast ratios
- Dark theme optimizations for extended coding sessions
