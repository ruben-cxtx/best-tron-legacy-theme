# Troning Markdown Lab

Markdown needs to read like documentation, not like a compromised code file.

## Quick Notes

- Headings should create hierarchy.
- Links should be obvious: [Troning Marketplace](https://marketplace.visualstudio.com/).
- `inline code` should feel connected to the terminal palette.
- Tables should stay calm and scannable.

> The Grid is easier to navigate when quotes, lists, code, and links each have their own signal.

| Token | Example | Goal |
| --- | --- | --- |
| Heading | `## Quick Notes` | cyan structure |
| Link | `[docs](...)` | active route signal |
| Code | `` `const program = true` `` | terminal signal |
